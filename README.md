# Capybara Springs

Cosy isometric capybara game (Vite + Three.js). Play: https://paper-rockets.github.io/Capy/

- Sunny Meadow: `https://paper-rockets.github.io/Capy/`
- Other maps: add `?map=old_orchard` (or `bamboo_woods`, `lotus_marsh`, `mountain_springs`, `moonlit_lake`, `misty_highlands`)
- Debug / screenshot mode: add `?debug&nosave`, e.g. `https://paper-rockets.github.io/Capy/?debug&nosave`
  - Travel: jump to any of the 7 maps
  - Free camera: drag to move, mouse wheel / pinch / + and - to zoom as far as you like
  - Hide buttons: clean screen for screenshots (tap "Show" top-left to bring them back)
  - `nosave` keeps your saved game untouched

Run locally: `npm install`, then `npm run dev` (http://localhost:8166).
